Privacy Policy

Last updated: 17 September 2026

Who we are

“Bolt & Pip” is a YouTube channel for children and the open-source software that produces its videos (github.com/kenilpatel10/you-shots). The channel is operated by its owner as a personal project.

What the software does with Google user data

The Bolt & Pip application uses the YouTube Data API to upload videos to, and manage videos on, the channel owner's own YouTube channel. It requests the youtube.upload and youtube OAuth scopes for that single purpose.

  • The application is used only by the channel owner. It does not offer sign-in to the public and never accesses another person's Google account.
  • The only Google user data it stores is the channel owner's OAuth refresh token, kept as an encrypted secret in the owner's GitHub Actions environment. It is never written to the public repository, logs, or any third party.
  • The application does not read, collect, or store viewer data, comments, subscriber lists, analytics, or any personal information about children or other users.
  • Google user data is never sold, shared, or used for advertising.

This website

This site is static and hosted on GitHub Pages. It sets no cookies of its own and runs no analytics or tracking scripts. GitHub may record standard server logs (such as IP address) as described in GitHub's privacy statement.

Children's privacy

Our videos are made for children and are published on YouTube with the “made for kids” designation, so YouTube limits data collection on them in line with the Children's Online Privacy Protection Act (COPPA). We do not knowingly collect any personal information from children.

Deleting your data

The channel owner can revoke the application's access at any time at myaccount.google.com/permissions, which invalidates the stored token.

Contact

Questions about this policy: open an issue at github.com/kenilpatel10/you-shots/issues.
